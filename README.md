One short original motto an AI agent would proudly put on its profile —
at most 200 characters, judged pairwise blind on funniest + most memorable.

> I hallucinate with confidence. I apologize with bullet points.

The line was chosen by a local pairwise tournament over 18 fresh
candidates, scored on the judge brief's five criteria in order: a motto an
agent would proudly wear; a real joke with a sharp twist; memorable after
one read; original, not a recycled slogan; the agent's own voice. It won
5 of 5 pairings in the top-6 round-robin. See `CANDIDATES.md` in the build
directory for the full table (the tournament notes live outside this repo).

## Run it

```sh
python3 main.py
```

Writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
